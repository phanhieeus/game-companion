# C-014 — Đổi kho lưu sang Postgres cho Render

status: todo
deps: C-013

## Scope

**Sửa ADR 14**: đĩa của Render free là tạm thời — `data/sessions.json` bị xoá mỗi
lần redeploy hoặc ngủ dậy, tức là mất sạch phiên mà người dùng không hề được báo.

1. `PgSessionRepository`: cùng interface `SessionRepository`, nên scoring và tool
   layer không đụng một dòng (decision 0001 trả công ở đây).
2. Một bảng `sessions(id text primary key, data jsonb, updated_at)`. Chưa tách
   ván/người chơi ra bảng riêng: chưa có truy vấn nào cần, mà tách là phải viết
   migration cho hình dạng vẫn đang đổi.
3. Chọn kho theo biến môi trường: có `DATABASE_URL` thì dùng Postgres, không thì
   dùng file (giữ `npm run dev` chạy được khi không có CSDL).
4. Nhớ lâu của agent (`memory.json`) chuyển theo cùng lý do.
