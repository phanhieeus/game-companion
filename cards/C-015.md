# C-015 — Deploy lên Render: một tiến trình phục vụ cả API lẫn web

status: todo
deps: C-014

## Scope

**Sửa ADR 3** ("chưa deploy, chạy local"): giả định rủi ro nhất — độ chính xác
giọng nói tiếng Việt — cần HTTPS thật để đo trên điện thoại, mà `adb reverse`
chỉ dùng được với đúng một máy cắm dây.

1. Server phục vụ luôn `dist/` đã build, và trả `index.html` cho mọi đường dẫn
   không phải `/api/*`. Local vẫn hai tiến trình (vite có hot reload); production
   một tiến trình.
2. `express` và `dotenv` chuyển từ `devDependencies` sang `dependencies` — Render
   không cài dev deps, thiếu là chết ngay lúc khởi động.
3. `render.yaml`: build `npm ci && npm run build`, start `npm start`, khai báo
   `GEMINI_API_KEY` (đặt tay, không commit) và `DATABASE_URL`.
4. Kiểm micro thật trên điện thoại qua HTTPS — đây là thứ chưa từng đo được.

## Allowed files

- `server/index.ts` (phục vụ tĩnh), `render.yaml` (mới)
- `package.json` (chuyển dependencies, script `start`)
- `flow/04-adr.md` (sửa quyết định 3)

## Verify (run these before calling the card done)

- [ ] `npm ci && npm run build && npm start` trên máy sạch → mở `localhost:8787`
      thấy app, không cần vite
- [ ] Đường dẫn sâu (`/whatever`) trả `index.html`, không phải 404
- [ ] `/api/*` vẫn là API, không bị nuốt bởi route tĩnh
- [ ] Render build xanh, log khởi động báo có `GEMINI_API_KEY`
- [ ] Mở trên ĐIỆN THOẠI qua HTTPS: nút micro xin quyền và nghe được tiếng Việt
