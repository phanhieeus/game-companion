status: done

## Scope

**Dữ liệu phiên và luật chơi chuyển sang server** (ADR 13, 14).

1. Chuyển `domain/` (types, scoring, errors), `tools/` và `repository/` từ `src/`
   sang `server/`. **Không đổi một chữ ký nào** — cùng code, đổi chỗ ở. Test theo
   cùng, vẫn phải xanh nguyên vẹn.
2. `FileSessionRepository` mới: lưu JSON xuống `data/sessions.json`, ghi kiểu
   ghi-file-tạm-rồi-đổi-tên để không nát file khi tắt giữa chừng. Cùng interface
   `SessionRepository` với bản localStorage/memory (decision 0001).
3. REST cho mọi thao tác TAY: tạo phiên, ghi/sửa/xóa ván, hoàn tác/làm lại, thêm
   bớt người, đổi cài đặt, kết thúc, đọc nhật ký ván. Đúng bảng ở
   `flow/05-contract.md`.
4. Lỗi trả về giữ nguyên `code` của tool layer, để UI phân biệt lỗi luật chơi với
   lỗi hạ tầng.

Server chạy `.ts` thẳng bằng Node 24 (type stripping) — không thêm bước build,
không thêm dependency. Đổi lại: import phải ghi rõ đuôi `.ts`.

KHÔNG thuộc card này: agent (C-012), sửa client (C-013). Sau card này client vẫn
chạy bản localStorage cũ — hai bên tồn tại song song đúng một card.

### Hai điều chỉnh so với card

1. **`src/agent/` đi cùng chuyến, không đợi C-012.** Card viết là client vẫn chạy
   bản cũ hết card này, nhưng agent import thẳng `../domain` và `../tools` — để
   nó ở lại thì cây code trỏ vào đường dẫn không còn tồn tại. C-012 vẫn làm phần
   HÀNH VI (route, chốt HITL ở server); card này chỉ dời chỗ ở.
2. **Types tách sang `shared/`, không nằm trong `server/`.** Client vẫn cần biết
   hình dạng `Session`/`Round` để vẽ bảng — đó là hợp đồng chung, không phải nội
   bộ backend. Để client `import` từ `server/` mới là sai ranh giới.

### Lỗi chỉ chạy thật mới lộ

Node chạy `.ts` bằng cách XOÁ phần kiểu, nên cú pháp nào SINH RA code thì không
chạy được. `constructor(private readonly path = …)` (parameter property) làm
server chết ngay lúc khởi động:

```
SyntaxError [ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX]:
TypeScript parameter property is not supported in strip-only mode
```

`tsc --noEmit` xanh hoàn toàn — chỉ `node server/index.ts` mới bắt được. Sửa:
gán tường minh trong thân constructor.

### Ghi chú thiết kế

- **Mọi `ErrorCode` đều là lỗi luật chơi**, không mã nào nghĩa là "máy hỏng" —
  nên tất cả ra 400 với `retryable: false`, và quy tắc đó không thể lệch theo
  thời gian. Lỗi hạ tầng đi đường khác: ném exception → error handler → 500.
  Bản nháp đầu tôi bịa ra một danh sách mã 4xx với ba cái tên không tồn tại
  (`ROUND_NOT_ZERO_SUM`, `PLAYER_NOT_FOUND`, `NOTHING_TO_UNDO`).
- **Ghi file tạm rồi `rename`** thay vì ghi đè thẳng: `rename` là nguyên tử nên
  tắt máy giữa chừng không để lại file nửa vời.
- **Phiên và bảng điểm luôn trả về cùng nhau** — client không tự tính điểm nữa,
  nên không có cơ hội lệch với server.
