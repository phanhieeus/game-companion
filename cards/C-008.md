# C-008 — Tool layer của agent và chốt xác nhận HITL

status: done
deps: C-007

## Scope

**Danh mục việc agent làm được, và chốt ai được phép chạy mà không hỏi.**

1. `AgentTool` — hình dạng một tool: tên, mô tả, schema tham số, cách chạy.
2. 15 tool phủ đúng những gì tay làm được: ghi/sửa/xóa ván, hoàn tác/làm lại,
   xem điểm, xem lịch sử, thêm/bớt người, đổi thứ tự bảng, bật tắt xác nhận,
   kết thúc phiên, nhớ/liệt kê/quên.
3. **`needsConfirm` khai ở TOOL, không ở model** (ADR 12). Model chỉ đề xuất;
   code quyết định câu nào phải hỏi người trước khi chạy.
4. Tool cũng tự khai **cái gì hiện lên lúc hỏi**: `propose` trả về các dòng số
   để UI vẽ thẻ đề xuất. Cùng lý do ADR 12 — nếu để model soạn câu hỏi thì đổi
   prompt là mất luôn con số người ta cần nhìn để bắt lỗi nghe nhầm.

Nguyên tắc: mọi tool đi qua đúng tool layer đã có (`src/tools/index.ts`,
decision 0001) — validate zero-sum, nhật ký, undo/redo dùng chung một đường,
KHÔNG có lối tắt riêng cho agent.

KHÔNG thuộc card này: vòng lặp gọi model (C-009), trí nhớ và nối vào UI (C-010).
