# C-016 — Kiểu qua dây sinh từ OpenAPI cho client

status: todo
deps: C-015

## Scope

**Nối lại chỗ đứt do đổi ngôn ngữ** (ADR 17).

Trước đây client và server dùng chung `shared/types.ts` — một định nghĩa duy nhất
cho `Session`, `Round`, `Scoreboard`. Backend Python cắt đứt đường đó. Khai tay
hai bản thì sớm muộn cũng lệch, mà lệch kiểu này IM LẶNG: pytest xanh, vitest
xanh, chỉ người dùng thấy sai.

1. FastAPI tự sinh `openapi.json` từ model Pydantic — dùng luôn cái đó.
2. Sinh `src/api/types.ts` bằng `openapi-typescript`, chạy qua `npm run gen:types`.
3. File sinh ra được commit (đọc diff thấy được khi hợp đồng đổi), có dòng đầu
   ghi rõ "SINH TỰ ĐỘNG — đừng sửa tay".
4. Xoá `shared/` khỏi tsconfig; client chỉ import từ `src/api/types.ts`.

## Allowed files

- `src/api/types.ts` (sinh ra), `src/api/client.ts`, `package.json`
- `shared/` (xoá), `tsconfig.json`
